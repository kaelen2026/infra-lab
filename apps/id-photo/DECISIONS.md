## 2026-06-19 决策:SEO 不投自然搜索大词,优先分享卡片

- 选了什么:把 SEO 力气放在「分享卡片(OG/Twitter) + 可索引地基 + 长尾隐私角度」,不为大词做关键词优化。
- 否掉了什么 / 为什么:
  - 为「证件照 / 在线证件照」大词优化 —— 这些词被成熟 App(智能证件照小程序、美图等)垄断,github.io 项目页近零域名权重,短期争不过,投产出比极低。
  - 为自然搜索预渲染落地页(SSG/prerender)—— 当前 CSR,正文靠 JS 渲染;但主渠道是分享而非搜索,且最关键的 title/description/OG 已是静态,先不值得为搜索引擎做这项工程。
- 当时的前提:部署在 `kaelen2026.github.io/id-photo-app/`(共享子域、零权重);定位是作品集 / 学习,获客主要靠手动分享链接(简历、社媒、IM),不是自然搜索;CSR 单页应用。
- 何时重审:迁到自有域名并积累了权重;或自然搜索真的成为目标获客渠道(那时再做落地页预渲染 + 针对长尾词建内容)。
- 相关:`index.html`(meta/OG/JSON-LD)、`public/og.png`(分享图);本次 SEO 审计见 commit `c68ef14`。
